## The Challenge
To establish a secure, repeatable network foundation without manual configuration errors.

## The Solution
* Designed a secure **Virtual Private Cloud (VPC)** architecture using Terraform.
* Configured Public Subnets, Route Tables, and Internet Gateways.
* Established secure external connectivity while ensuring strict network isolation.
