## The Challenge
Deploying a complex 3-tier application manually was slow and prone to downtime.

## The Solution
* Automated the CI/CD pipeline using **Jenkins, Docker, and Kubernetes (EKS)**.
* Implemented **ArgoCD** for GitOps-style continuous delivery.
* Used Terraform for infrastructure provisioning and set up GitHub triggers for automatic builds.
